# High Noon Flip

Before starting, read `docs/ROADMAP.md` (the plan, what is done, the decisions) and
`README.md` (commands and code layout). Work on one roadmap step per chat; when it is
done, tick it in the roadmap and commit.

`prototype/index.html` is the look-and-feel reference. Open it with the `prototype`
entry in `.claude/launch.json` (port 5174); the new client runs with `dev` (port 5173).

Before committing: `npm run typecheck && npm run lint && npm test`.
